# WME Scripts

Userscripts for the [Waze Map Editor](https://www.waze.com/editor) (WME). Each one lives in its own folder with a README that covers installation and usage. They run in [Tampermonkey](https://www.tampermonkey.net/).

| Script | Description |
|---|---|
| [WME Florida Functional Classification Overlay](wme-fl-funcclass/) | Overlays FDOT functional classification in Florida, colored by the Waze road type each class calls for. Flags under-typed segments and invalid `SR-` names. |
